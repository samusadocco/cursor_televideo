## 🔧 CODICE - Modifiche Unificate

### 1. Rilevamento Store e Piattaforma

Estendi `lib/core/utils/store_country_detector.dart`:

```dart
class StoreCountryDetector {
  // Già esistente
  Future<String> getStoreCountryCode() async { ... }
  
  // NUOVO: Rileva piattaforma
  Future<StorePlatform> getStorePlatform() async {
    if (Platform.isIOS) {
      return StorePlatform.appStore;
    } else if (Platform.isAndroid) {
      return StorePlatform.playStore;
    }
    return StorePlatform.unknown;
  }
  
  // NUOVO: Combinato
  Future<StoreInfo> getStoreInfo() async {
    final country = await getStoreCountryCode();
    final platform = await getStorePlatform();
    
    return StoreInfo(
      countryCode: country,
      platform: platform,
    );
  }
}

enum StorePlatform {
  appStore,
  playStore,
  unknown,
}

class StoreInfo {
  final String countryCode;
  final StorePlatform platform;
  
  StoreInfo({
    required this.countryCode,
    required this.platform,
  });
  
  // Helper per analytics
  String get analyticsString => '${platform.name}_$countryCode';
}
```

### 2. Analytics Unificata per Store

Modifica `lib/core/analytics/analytics_service.dart`:

```dart
class AnalyticsService {
  // Log apertura app con info store
  Future<void> logAppOpen() async {
    final storeInfo = await StoreCountryDetector.instance.getStoreInfo();
    
    await _analytics.logEvent(
      name: 'app_open',
      parameters: {
        'platform': storeInfo.platform.name,
        'country': storeInfo.countryCode,
        'store_combo': storeInfo.analyticsString, // es. "appStore_DE"
      },
    );
  }
  
  // Log revenue con differenziazione
  Future<void> logAdImpression(double revenue) async {
    final storeInfo = await StoreCountryDetector.instance.getStoreInfo();
    
    await _analytics.logEvent(
      name: 'ad_impression',
      parameters: {
        'revenue': revenue,
        'platform': storeInfo.platform.name,
        'country': storeInfo.countryCode,
        'cpm_tier': _getCpmTier(storeInfo.countryCode),
      },
    );
  }
  
  String _getCpmTier(String country) {
    switch (country) {
      case 'CH': case 'NO': return 'premium';
      case 'DK': case 'SE': case 'DE': case 'AT': return 'high';
      case 'FI': case 'IS': return 'medium';
      default: return 'standard';
    }
  }
}
```

### 3. Ads Frequency - Unificata per iOS/Android

```dart
// lib/core/ads/ad_config.dart

class AdConfig {
  static int getInterstitialFrequency(String country, StorePlatform platform) {
    // iOS: CPM più alto, possiamo mostrare più ads
    // Android: CPM più basso, compensiamo con più frequenza
    
    final baseFrequency = _getBaseFrequency(country);
    
    if (platform == StorePlatform.appStore) {
      return baseFrequency; // iOS: come base
    } else {
      return (baseFrequency * 0.8).round(); // Android: 20% più frequente
    }
  }
  
  static int _getBaseFrequency(String country) {
    switch (country) {
      case 'CH': return 3;  // Svizzera: CPM altissimo
      case 'NO': return 3;  // Norvegia
      case 'DK': case 'SE': case 'DE': case 'AT': return 4;
      case 'FI': case 'IS': return 5;
      default: return 6;
    }
  }
}
```

## 💡 BEST PRACTICES - Dual Platform

### ✅ DO:

1. **Stesso messaggio, design coerente**
   - User vede stesso brand su iOS e Android
   - Professional e coerente

2. **Link entrambi ovunque**
   - Email: "Disponibile per iOS e Android"
   - Social: Sempre entrambi i link
   - Sito web: Badge entrambi

3. **Monitor metriche separate**
   - iOS trend diverso da Android
   - Germania iOS ≠ Germania Android
   - Ottimizza per ciascuno

4. **A/B test separati**
   - Google Play: test nativo
   - Apple: test manuale
   - Confronta risultati

### ❌ DON'T:

1. **Non favorire una piattaforma**
   - Alcuni utenti solo iOS, altri solo Android
   - Entrambe importanti

2. **Non duplicare lavoro**
   - Crea asset una volta
   - Riusa per entrambe

3. **Non ignorare differenze**
   - iOS: più premium
   - Android: più volume
   - Strategie leggermente diverse
